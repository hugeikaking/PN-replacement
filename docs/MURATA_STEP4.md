双击新版 HTML，重新选择同一个 v3.1 整理结果目录中的 `normalization-summary.json` 和 `normalized-products.jsonl`。无需再次扫描或整理。数据只在当前页面内存读取；刷新或关闭后重新导入。CSP 禁止程序发起网络连接，规格书链接仍由用户主动点击打开。

## 查询行为

- 描述 → 村田：严格解析每行参数，调用正式记录 Matcher，仅返回导入记录中的完整料号；未导入时禁止查询，不回退规则拼接。
- 料号 → 规格：三星 CL 15 位、TDK C 19 位、太阳诱电 MS 20 位，沿用项目既有字段映射，校验完整结构及关键编码，再把容值、电压、英制封装、温度特性、精度转换为相同的官方查询。
- TDK 的 X7R 等编码与含义相同时仍保留字段，修复此前“含义等于原码就不显示”的问题。
- 太阳诱电用户真实样例 `MSASP063EB5475MFNA01` 保持 0201 / X5R / 4.7uF / ±20% / 2.5V，独立厚度码 3 为 0.3mm。
- 村田输入料号先精确查导入记录，读取记录规格，不靠编码猜。重复或冲突料号禁止使用；找不到完整料号时提示当前范围未覆盖，不能推断产品不存在。
- 村田记录没有可核对电压时保持未知，并按部分参数查询；有多项 DC/AC/安规额定值时显示所有可核对原额定值，不任选一项用于完整匹配。
- 封装、温度、容值、精度、电压关键编码未知或结构错位则停止候选查询。R 容值和现有乘数 0–7 可解析，乘数 8/9 未校准而拒绝，不套用旧算法得到极大电容。
- 太阳诱电 JMK/TMK 等旧体系、TDK CGA/CEU、其他未支持系列不套用相似结构。国巨与华新科旧草稿映射仍在历史引擎源码中保留，但不进入本步正式候选匹配，以免未经校准的资料驱动采购结果。
- 基础参数相同仅代表候选查询，片厚、包装、偏压等完整工程条件不在本步替代判断中；UI 明确注明需核对完整规格。

正常生产且字段一致的产品主组展示，NRND / 字段待核查默认折叠，普通复制不包括折叠组。保持第三步排序、AEC 标记、DC/AC/安规分离、冲突隔离、数据范围和规格书来源信息。用户明确选择折叠组后可单独复制。

## 复制及范围

v2.1 两模式各自保留输入、结果 DOM、勾选和 details 展开状态；切换只显示相应面板。“清除当前输入和结果”只重置当前模式，不移除另一模式或规格数据。重新导入规格文件会使两模式旧结果失效并清除，但保留输入，避免展示旧库候选。查询任务绑定各模式的 revision，清除、重新导入或卸载后异步查询不能重新填回旧结果；切换不取消另一模式查询。仅本页面运行期间保留，不写入浏览器存储。

v2.1 修正回贴描述：严格参数解析器仅移除 MLCC 前已知来源厂商标签（三星、太阳诱电、TDK 及对应英文名称），MLCC、参数顺序本来可解析。未知文字仍报错，不宽泛忽略额外条件。料号模式直接查询使用结构化字段，本来不受品牌文字影响；它的空候选仍需核对数据覆盖和具体参数。

每条规格描述可单独复制，多个描述一键按换行输出。官方候选保留逐个、勾选、各查询主组及跨查询主组复制，跨查询料号去重。复制“当前显示”只包含已展示条目。每组从 20 个逐次增加至 500 个，明确显示总数；仍支持最多 100 行，当前要求每行一个物料。

JSONL 导入沿用第三步 128MB / 100000 记录限制，不应载入原始 368MB 数据库。全库部署、权限、服务端共享和 API 不属于本步。

## 知识库与历史

保留 H5 文字 / PDF / 图片存档和查阅。上传资料不会自动提取或发布编码映射，文字模糊匹配也不驱动正式候选。修正旧页面“所有人可用”的说明：目前仅当前浏览器保存，不共享，没有 PDF 表格提取、OCR 或服务端知识库。

官方记录与本步查询历史只保存在内存，不写入 localStorage；旧缓存中的拼接料号不再作为官方结果加载。浏览器原有知识库存档未删除，旧历史缓存未删除但不重放。首页历史重新查询时先切模式再填入输入，避免清空。
