# v2.6.5：高容产品替代候选

仅用于“描述 → 村田料号”。先执行原严格查询；没有符合原已识别参数的正常生产候选，且原描述容值至少 1uF 时，才执行替代查询。已有正常候选（包括 RO 未确认时已识别参数相同的候选）不再放宽参数。原条件下的待核查/NRND 记录单独保留。

## 已确认规则

- 容值只允许原值或导入目录中紧邻的更大容值。例如目录依次有 2.2、3.3、4.7uF，输入 2.2uF 只允许升至 3.3uF，不能因 3.3uF 没有合适型号而继续升至 4.7uF。
- 电压只允许原值或同类型、同安规类别的紧邻更高额定值，不跨 DC/AC 或 X1/X2/Y1/Y2 类别。
- 温度特性不能按名称直接排序。只对已校准的 EIA Class 2 定义，取工作温度上限更高、下限范围不收窄、允许温漂不变差的最近上限档位。例如 X5R 的 ±15% 不会改成 X6S 的 ±22%；目录存在 X7R 时可作为温度范围扩大的候选。非 EIA 或未校准特性仍可保持原特性，但不自动改成其他温度特性。
- 封装优先保持原尺寸，否则只允许目录中相邻的小一档标准封装，不允许放大或连续缩小多档。比较已有标准封装的物理长宽，两边均不得变大，按面积选最近较小档位；英制/公制身份明确转换。未知封装代码不猜测尺寸。
- 可同时改变多个参数，每项仍只能按上述规则变化一档。同尺寸候选先列出，再按改变项目数较少优先。
- 精度、H 最大高度、明确填写的实际长宽、应用、AEC 条件及系列要求不放宽。缺少明确封装、电压、温度或容值时不执行替代。

“档位”来自本次导入目录的去重值，不是官网固定档位，也不是某一组规格中的下一个可用型号。非冲突的待核查记录也参与定义档位，防止跳过中间档。候选本身只来自正常生产且字段一致、应用和其他条件已符合的记录；不拼接料号，不把未知 RO 当作满足条件。

温度定义依据：[村田温度特性说明](https://article.murata.com/en-global/article/temperature-characteristics-electrostatic-capacitance)。可维护规则在 src/rules/shared/substitution.json，标准尺寸沿用 size-codes.json（补充微型尺寸身份）。这只是参数规则，不代表增大容值、提高耐压或缩小封装即可直接替换；焊盘和实际电路仍需核对。

## 页面和导出

替代候选采用单独的浅黄色分组，料号旁明确展示“替代候选（非精确匹配）”及原值 → 候选值，每项变化都会保留。点击料号展开原规格与完整提示。

替代不会混入正常匹配的一键复制、普通 Excel/CSV 导出或“打开当前结果规格书”。需明确勾选后使用“复制已选”“导出已选 Excel”“打开已选规格书”。已选 Excel 有独立替代分组、匹配类型和“与原描述的差异”列，汇总分别记录替代总数和当前显示数。规格书弹窗仍可二次选择，每次点击打开一份。

## 公司验收

先用一个已知能精确匹配的描述，确认结果不变且无替代分组。再用无正常匹配的 ≥1uF 描述，检查每项差异和档位；低于 1uF 不应出现替代。不同导入目录的档位可能不同，不指定未核验的真实料号作为必出结果。

勾选替代候选后，核对复制、已选 Excel、规格书弹窗三者的料号一致；普通导出与正常复制不应含替代。复测最大高度、精度、应用和 AEC 筛选，及 A/B 切换、清除、显示更多的选中状态。
