Murata 第一步核验工具 v3

把压缩包里的三个 .ps1 文件和本说明解压到公司桌面的 Murata-Step1-v3 文件夹。
本工具读取公司本机已有数据库和检查结果，不需要 API Key，不联网、不上传文件。

在 Windows PowerShell 里执行：
powershell.exe -NoProfile -File "$env:USERPROFILE\Desktop\Murata-Step1-v3\Continue-MurataDataCheck.ps1"

不需要另跑检查脚本：续查完成后自动生成 local-review-*.html，双击打开。
默认读取桌面 Murata_Data_Check 最新创建的结果目录，从上次结束位置继续。
默认最多检查新增 100000 条，优先查找 GRM、KRM。找到两系列并凑满1000条预览可提前结束。
达到上限也是正常停止；未找到系列不能直接证明全库不存在。
新结果单独保存，旧报告保留。每个报告只代表本次范围，需要结合旧报告看覆盖情况。

源数据库必须保持不变。文件大小或修改时间变化、前次失败或已到文件末尾时，工具会停止并说明原因。
前面产品仍需顺序跳过，并非瞬时跳转；窗口会显示跳过及扫描进度。

v3 会识别千位逗号，10,000pF 与 0.1µF 都归入实际 nF 范围。
新增换算列只来自明确的文字单位，不改官方原值、不自动认定原数字字段单位。
ERROR 是运行/一致性问题；TODO 是仍待人工核对；UnitsVerified/SchemaVerified=false 不是报错。

若执行策略拦截，请使用公司 IT 允许的执行方式，不修改全局策略。
本机只用合成数据测试。公司产品规格、单位、生命周期和规格书仍需公司本地确认。
