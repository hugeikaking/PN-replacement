# 第五步：批量文件输入与查询结果导出（v2.5）

## 本次完成

H5 的“批量翻译”入口和单文件离线网页共用同一个界面、解析引擎及官方记录查询。两个模式都支持导入 .xlsx、.xls 和 CSV UTF-8：选择工作表、输入列、是否有标题，预览后导入当前模式输入框，再点击查询。每格须是一个完整描述或完整料号；本步不拼接分散在多个列的规格。

文件上限 5MB，每次最多 100 条非空输入。表格范围最多 1001 行、100 列、50 个工作表，过大时整份拒绝，不悄悄截取记录。空行跳过但原表行号保留，Excel 显示格式中的前导零保留；所选输入列的公式（即使含缓存值）、布尔值、错误单元格或内部换行提示处理后重新导入。非输入列的公式不参与查询。

批量文件、映射选择、输入、结果分别保存在 A/B 模式的页面内存中。切模式保留，手动清除仅清当前模式。重新导入官方目录清除旧查询结果但保留输入；手动修改输入则移除原文件行号映射，避免输出错配。本步不实现刷新、关闭页面或路由卸载后恢复整张批量结果。

## 导出

查询结束后可导出当前结果 Excel、当前结果 CSV，或明确勾选的料号 Excel。Excel 有“查询汇总”“候选明细”两张表，通过输入序号关联；CSV 把查询与候选展开到同一张表。查询汇总保留原输入、来源文件/工作表/原行号、规格描述、应用条件、范围、错误/缺失条件/提示；识别失败和无候选也有一行。候选包含原记录料号、基础参数、DC/AC 和安规额定类别、生命周期、AEC-Q200、应用、标准、特征及其依据、未核验链接。

普通导出只包含当前显示的正常生产候选，不自动选一个结果，不把 NRND/待核查当成普通候选。明确勾选的待核查料可通过“导出已选料号 Excel”输出，结果分组标明“待核查（明确勾选）”。候选总数与当前显示数分别保存；点击“显示更多结果”后再导出会更新当前显示范围，不承诺导出目录内所有匹配。已选导出的查询汇总保留全部输入，明细只保留已选候选。

Excel 单元格写为文本，不创建公式。CSV 正确转义引号、逗号、换行，以 UTF-8 BOM 输出；对于可能被 Excel 视为公式的前缀增加文本标记。模板是当前模式的两行 CSV 样例。

## 公司使用

1. 通过公司允许的渠道取得完整的 `Passive-PN-Translator-v2_5.html`；不要通过修改浏览器安全设置排错。
2. 沿用 v3.4 分类转换器产生的同一目录内 `normalization-summary.json` 与 `normalized-products.jsonl`。本步无需重整已有数据，新网页没有附带数据库。
3. 展开“批量导入 Excel / CSV”，下载模板或选择自己的输入文件，选列、核对预览后导入，设置应用范围并查询。
4. 验证正常、失败、无候选输入均保留；两模式切换保留；下载结果并核对原表行号与候选分组。

使用样本仍只查询样本；导入批量输入文件不会增加产品目录覆盖。完整目录、公司 API 接入和统一验证在后续公司阶段；报价申请 Excel 的模板自动填写最后实现，本次导出不填写公司的报价申请表。
