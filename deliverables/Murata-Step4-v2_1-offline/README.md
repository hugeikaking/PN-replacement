# 物料与料号互译 v2.1

打开同目录 `Passive-PN-Translator-v2_1.html`。版本应为 v2.1。通过公司批准的渠道部署，不需 API Key 或重扫数据库。

选择之前同一次整理的 `normalization-summary.json` 和 `normalized-products.jsonl`。

两个翻译模式分别保留输入、查询结果、勾选和展开状态。切换不清空；输入框上方“清除当前输入和结果”只清当前模式，保留另一模式和已导入数据。保留范围为本页面运行期间，刷新或关闭后重新导入。

复制出的“三星 / TDK / 太阳诱电 + MLCC + 参数”描述可原样粘贴到描述模式查询。原先厂商名称被当成未知文字的问题已修正；厂商标签不限制村田候选。基础参数仍须相符，空候选不代表村田没有该产品。

验证方式：料号模式输入 `MSASP063EB5475MFNA01`，复制描述粘贴到描述模式，查询后反复切换；两边输入和结果应都保留。清除其中一个模式，另一边应不受影响。相同数据下，直接料号查询与粘贴描述查询应有相同候选。

源码测试使用合成记录，不打包测试产品或公司数据库。公司 API 第六步再接，报价申请 Excel 最后做。
