这是原始产品目录归档工具，与现有 v2.5 网页、MLCC 整理脚本分开使用。

村田官方页面 https://www.murata.com/en-global/support/api 确认 API v3 支持 73 个类别，并提供获取全量规格 JSON 下载链接的接口。73 个类别不等于官网所有产品都一定开放给当前账号；能否下载以接口实际返回为准。

2026-10-08 已读取用户提供的 murata-products-info-openapi-zh (1).json，标题“产品信息API 版本3.0”。随附 categories-v3.txt 从 components.schemas.products-v3.properties 的 73 个类别键名及其对应 schema 引用提取，逐字保留大小写，没有按中文名称猜测。类别名称和来源校验值见 categories-v3-index.json。随附 categories-mlcc-smoke-test.txt 只有 ceramicCapacitorSMD，供首次试运行，不是完整目录。文档中的 category 参数本身没有 enum；清单来源是其 73 类产品结构定义，实际接口仍需公司运行确认各类权限和响应。

先在公司电脑确认一类

1. 把 Download-MurataProductCatalogs.ps1 和 categories-mlcc-smoke-test.txt 放在同一目录，用公司允许的方式取得原始文件。
2. 在该目录打开 PowerShell，运行：

```powershell
powershell.exe -NoProfile -File .\Download-MurataProductCatalogs.ps1 -CategoriesFile .\categories-mlcc-smoke-test.txt -ExpectedCategoryCount 1
```

3. 提示输入 API 密钥时在公司电脑输入。输入不回显，工具不把密钥写进文件。不要把密钥发给开发者。工具使用之前确认的 v3 endpoint 和 x-api-key 请求头。
4. 默认用中文 lang=zh。文档明确支持 ja、zh、en，其他语言可指定 -Language en 或 ja。
5. 此 v3 文档已确认 GET /v3/products/getproductdatadownloadurl，返回对象包含 Category、Language、ProductDataDownloadUrl，密钥请求头为 x-api-key；默认字段不需要调整。文档说明下载链接在生成后 7 天内有效。工具每次取得新链接后立即下载，不复用文档中的旧示例链接。

下载完整类别清单

把随附 categories-v3.txt 与下载脚本放在同一目录，确认单类试运行成功后，下载此文档定义的 73 类：

```powershell
powershell.exe -NoProfile -File .\Download-MurataProductCatalogs.ps1 -CategoriesFile .\categories-v3.txt
```

默认要求恰好 73 个不同 ID；缺少、重复或格式异常时会在联网和询问密钥之前停止。若只需要部分已确认类别，可明确指定 -ExpectedCategoryCount 实际数量。数量校验不能代替对照官方清单核验 ID。

文件很大时先确认保存盘有足够空间。可改到公司本地数据盘，例如：

```powershell
powershell.exe -NoProfile -File .\Download-MurataProductCatalogs.ps1 -CategoriesFile .\categories-v3.txt -OutputRoot 'D:\Murata_Product_Archives'
```

每次会新建目录，例如 Desktop\Murata_Product_Archives\download-日期时间-随机编号，已有目录和 Murata_MLCC.json 不会被覆盖。下载过程逐类执行；失败类别可从清单中单独挑出来重试，新一次会保存到新目录。默认类别间隔 2 秒并不是已核实的官方限速；如果你的手册要求更慢，可用 -IntervalSeconds 设置 2 至 60 秒。

结果如何看

- 每类单独一个 category-zh.json：原始 JSON 文件内容，不做规格转换，不合并产品类型，不自动导入网页。
- download-manifest.jsonl：每类的结果、阶段、HTTP 状态（有返回时）、大小、SHA256、UTC 时间。
- run-summary.json：请求类别、成功/失败/未尝试数量、整体结果。只有清单中所有类别均下载成功才显示 all-requested-files-downloaded。
- *.partial：未通过下载或 JSON 检查的文件；不要导入网页。失败后不会被改名成正式 JSON。

工具会流式下载和检查 JSON 语法，不把大文件整体加载进 PowerShell 对象。语法通过只能说明取得了 JSON 对象/数组，不能验证产品结构、数量、网站覆盖率、生命周期、规格书或选型正确性；也不能排除服务返回内容格式正确但含业务错误。确认每类格式后才能接入后续翻译工具。

API 请求返回 401/403 会停止后续类别，不反复请求。临时网络错误、429 或 5xx 最多尝试三次。不更改公司代理、证书验证或运行策略；不自动打开或执行下载内容。文件下载请求不携带 x-api-key，日志不保存下载链接或密钥。
