# 物料与料号互译 v2.0（第四步）

打开同目录 `Passive-PN-Translator-v2.html` 即可，无需安装。

导入原 v3.1 整理目录中的 `normalization-summary.json` 和 `normalized-products.jsonl`，无需重新扫描。文件由本机浏览器读取，不上传；关闭网页后需重新导入。使用公司批准的渠道部署本文件。

两个入口：描述查真实村田料号；料号先拆解规格，再查村田候选。未导入数据也可先解析三星 CL、TDK C、太阳诱电 MS 料号。其他系列或旧料号尚未校准会明确提示。

料号模式测试三行：

```
CL10B104KO8NNNC
C1608X7R1H104K080AA
MSASP063EB5475MFNA01
```

最后一行应解析为：太阳诱电 MLCC 0201 X5R 4.7uF ±20% 2.5V。

村田候选可能因样本未覆盖而为空。支持逐条及一键复制规格描述，多个结果按换行；官方料号仍支持勾选与复制，NRND 默认折叠。候选基础参数匹配不等于工程替代验收。

详细说明见项目 `docs/MURATA_STEP4.md`。公司 API 第六步再接，报价申请 Excel 自动填写最后实施。
