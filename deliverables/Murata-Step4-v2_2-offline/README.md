# 物料与料号互译 v2.2：无结果原因检查

打开 `Passive-PN-Translator-v2_2.html`，确认右上角版本 v2.2。重新导入原有同一次整理的 `normalization-summary.json` 和 `normalized-products.jsonl`，无需重扫或重新整理。

描述解析成功但没有候选时，新版会展示“为什么没有匹配结果”：本次导入范围和记录数、每个识别条件、单独符合该条件的记录数、同时符合本行及前面各条件的记录数。

例如容值 4.7uF 的“单独符合”是 0 条，只能说明这份可查询数据没有相同容值记录；不能证明官网没有。若所有条件单独都有记录，但组合剩余 0 条，说明导入数据里没有完整相符的一条记录。

只差一个条件时会显示“仅不限制该条件，其余条件相符”的记录数，帮助定位条件差异；不会自动放宽条件、把这些记录列为候选或宣称可替代。计数含 NRND / 待核查记录，排除缺失和冲突料号，仍区分 DC / AC / 安规电压与未知值。

如果公司页面仍无法查询，请提供该区域照片、输入描述和你找到的村田完整料号即可。公司数据文件留在公司，本工具不上传数据。

两个模式的输入与结果保留、分别手动清除和换行复制继续保留。公司 API 第六步，报价申请 Excel 最后做。
