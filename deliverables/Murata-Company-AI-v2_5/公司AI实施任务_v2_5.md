# 公司 AI 实施任务：把现有料号翻译网页升级到 v2.5

使用方法：将本文全文交给公司 AI，并同时提供公司电脑上当前能正常运行的 v2.4.1 HTML 文件；如果有项目源码，也一并提供。本文是功能实施要求，不包含产品数据库或 API 密钥。公司数据留在公司环境处理。

以下内容可直接作为公司 AI 的提示词。

## 1. 你的任务和工作范围

你是维护已有软件的开发助手。请先读取我提供的现有代码，再在现有可运行版本上补齐下面的 v2.5 功能。请直接实施、检查并交付文件，不要只给计划、示例或一份从零重写的简化网页。

本次升级的核心是：**批量导入物料描述或竞争厂商料号，以及导出查询结果。**

三类应用筛选、标准（安全规格）、特征、竞争厂商料号解析、村田目录查询、两种模式切换和手动清除按钮，都是已有功能。本次保留并复用，不重新设计它们。

先确认收到的文件能正常启动。如果没有收到现有代码，或基线本身不能启动，请说明缺少什么或具体错误；不要靠猜测重建引擎。保留原文件，另存升级文件 `Passive-PN-Translator-v2_5-company.html`。不要覆盖原版、公司数据库或已生成的目录文件。

### 必须保持的边界

- A 模式：描述 → 村田料号。B 模式：竞争厂商料号 → 规格描述，再复用现有村田查询。
- 所有输入都走现有解析、严格参数匹配、应用筛选和生命周期分类。批量功能只负责输入、关联行号、展示与导出，不改变匹配条件。
- 村田候选只能来自已导入的真实产品记录。不得根据规则拼接新料号，不自动补齐缺失电压，不降低条件以制造匹配，不自动选第一个候选。
- 沿用同一结果目录内的 `normalization-summary.json` 与 `normalized-products.jsonl`。这两个是产品目录文件；本次新增的 Excel/CSV 是查询输入文件，两者用途不同。
- 本次无需重新生成已有产品目录。样本查询仍只是样本查询；导入 Excel/CSV 不会扩大目录覆盖，不能宣称已接入完整官网目录。
- 无勾选应用时仍默认民用设备/工业设备，多选仍按已有逻辑处理。AEC-Q200 与应用适用范围独立，不据 AEC 或料号前缀猜应用。
- 标准、特征及依据沿用已有字段和分类逻辑。不得把 EIA/JIS 温度标准当作安全认证，不得把 C0G 自动解释为 High Q。缺失值、false、未知保持原意。
- 本次不接公司 API，不修改竞争厂商编码规则，不做报价申请 Excel 自动填写，不上传公司文件或输入数据。

## 3. 批量导入界面与行为

在 A/B 两个模式的输入框附近增加可展开面板“批量导入 Excel / CSV”，包含：

1. 文件选择，支持 `.xlsx`、`.xls`、`.csv`。
2. “下载当前模式 CSV 模板”按钮。
3. 工作表选择、输入列选择、“首行为标题”复选框，默认有标题。
4. 前 5 条有效输入预览，显示文件名、有效条数和原表行号。
5. “导入到当前输入框”按钮，明确提示此操作将替换当前模式的输入。

选文件和切换列只更新预览，不立即改输入框。验证全部通过后，点击导入才替换当前模式输入、清除该模式旧查询结果。导入不自动查询，用户继续点击现有查询按钮。

每个输入格必须是一个完整物料描述或一个完整料号。本版不把尺寸、容值、电压等分散列自动拼成描述。

### 文件读取要求

| 项目 | 要求 |
| --- | --- |
| 文件大小 | 非空，最多 5 × 1024 × 1024 字节 |
| 查询数量 | 每次最多 100 条非空输入 |
| 表格范围 | 每表最多 1001 行、100 列；工作簿最多 50 个工作表 |
| 单条长度 | 最多 1000 字符；导入后整段文字最多 100000 字符 |
| 空行 | 跳过空输入，保留原表行号，不把后续行重新编号 |
| 标题 | 勾选时跳过该表读取范围的第一行；无标题可取消 |
| Excel 格式 | 优先保留显示文字，如数值 402 的 `0000` 显示格式应读作 `0402` |
| 所选输入列公式 | 即使有缓存结果也拒绝，提示复制并粘贴为值；非输入列公式不影响输入 |
| 其他非法格 | 所选列的布尔值、错误单元格、内部换行拒绝，提示原行号 |
| 超限或非法输入 | 整次导入拒绝，不截取前 100 条，不部分替换现有输入 |
| CSV 编码 | 严格 UTF-8，接受 BOM；其他编码提示另存 CSV UTF-8 |
| CSV 分隔与转义 | 支持逗号、分号、制表符；正确解析带引号内容和双引号转义，拒绝未闭合引号 |

CSV 不能直接用 `split(',')` 或简单按换行切格。允许 CSV 解析器识别带引号的换行，但最终所选输入格有内部换行仍应拒绝，避免一个物料被拆成多条。

Excel 读取不能只读取上限内的前几行后就宣称文件合格，应核对真实表格范围。例如库提供 `!fullref` 时应优先检查它，不能因 `sheetRows` 截断掩盖超限。

## 4. 两种模式、来源行号和异步任务

A/B 分别保存以下页面内状态：输入、结果、已勾选料号、应用选择、上传文件、工作表、输入列、标题选项、预览、来源行号。

- 切换模式后再切回来，上述内容保留，不自动清空、不自动把 B 的描述写入 A。
- “清除当前输入和结果”只清当前模式的输入、结果、文件和映射；保留另一模式、已导入产品目录和应用选择。
- 手动修改输入或点击示例后，解除当前输入与原文件行号的关联，避免把新输入标为旧文件来源。
- 重新导入产品目录时，清除两模式旧查询结果，但保留输入与批量文件映射。
- 异步读文件和查询必须绑定所属模式及任务版本。切模式、清除或选择新文件后，旧任务不能把结果写入另一模式，也不能恢复已经清除的内容。
- 本次只要求当前页面会话内保留，不要求刷新、关闭网页后恢复整份文件或查询结果，不新增公司数据持久化。

每条查询保存自己的快照：原输入、来源文件、工作表、原表行号、A/B 模式、查询时的应用条件、解析结果、候选与错误。导出使用该次结果快照，不能读取后来编辑过的输入框或新改的应用条件造成错配。

手工输入多行时，来源文件和工作表为空，行号对应输入框原行号。文件输入跳过空行后，仍保留原 Excel 行号。例如第 2、4、5 行有数据，导出应仍是 2、4、5。

逐条复用现有查询。某条无法识别时保留该条错误，其余有效条继续处理。不要把文件结构验证失败与单条查询失败混为一谈。

## 5. 导出按钮及结果规则

查询完成后保留已有复制按钮，并新增：

- “导出当前结果 Excel”
- “导出当前结果 CSV”
- “导出已选料号 Excel”

普通导出仅包含**当前已显示的正常生产候选**，不自动包含 NRND/待核查候选。不保证导出全部匹配；候选总数与当前显示数分别保存。用户点击已有“显示更多结果”后，再次导出应更新显示范围。

“已选”导出只包含用户在各条查询下明确勾选的候选。没有勾选时提示，不下载空文件。用户明确勾选的待核查候选允许导出，但分组必须写“待核查（明确勾选）”，生命周期原文保留，不写成正常生产。相同料号出现在不同查询时，要按各自查询的勾选关联，不用一个全局集合造成误选。

Excel 生成真正的 `.xlsx`，含两张工作表：

- “查询汇总”：每条输入一行，包括错误、无匹配、仅解析未查询目录的输入。
- “候选明细”：每个候选一行，通过“输入序号”关联查询汇总。

已选导出的查询汇总仍保留全部输入，明细只含已选候选。CSV 将查询信息与候选展开在同一张表，多候选多行；无候选和错误输入仍保留一行，候选列留空。

### 查询汇总列（按此顺序）

输入序号、来源文件、工作表、原表行号、翻译方式、原输入、规格描述、查询状态、应用筛选、目录范围、正常生产候选总数、正常生产当前显示数、待核查候选总数、待核查当前显示数、缺少条件、错误、查询提示。

查询状态区分：输入或查询错误、仅解析未查询目录、有正常生产候选、仅有待核查候选、当前目录范围无匹配。

目录范围据实际导入记录标记。样本写“导入的样本范围”；Full 写“Full 模式导入记录（完整性见数据汇总）”，不能只凭 Full 标签保证全库已完整读取。

### 候选明细列（按此顺序）

输入序号、村田料号、结果分组、是否已选、匹配类型、容值(pF)、英制封装、公制封装、温度特性、精度、电压（类型/安规类别/状态）、生命周期原文、AEC-Q200、应用、应用依据、标准（安全规格）、标准依据、特征、特征依据、规格书（未核验）、安全证书（未核验）、候选提示。

容值统一导出已有校验值 pF，不重新猜测原始数值单位；未知留空。精度带单位，百分比与 pF 不混用。DC/AC、X1/X2/Y1/Y2 按记录分别输出，不互相替代。AEC-Q200 的 true/false/null 分别为是/否/未知。原链接只是未核验文字，不声称证书已经校验。

### 文件正确性

- Excel 将所有导出内容作为文本单元格，不能创建公式；中文、长料号、前导零应保留。
- CSV 输出 UTF-8 BOM，正确转义逗号、双引号、换行。
- 仅加 CSV 引号不能防止公式执行。对开头可能被表格软件当作公式的 `= + - @`（包括前置空白）添加文本标记；不执行输入文件中的公式。
- 不把 CSV 改名 `.xlsx`，不只导出成功的第一条，不把多个候选塞成一个无法关联的料号字符串。

## 6. 模板和 Excel 库

A 模式 CSV 模板列名为“物料描述、备注”，提供两条样例：

- `008004 10pF 16V C0G ±2%`
- `0805 10uF 16V X5R ±10%`

B 模式 CSV 模板列名为“料号、备注”，提供两条样例：

- `CL10B104KO8NNNC`
- `MSASP063EB5475MFNA01`

样例只用于验证输入与解析，不承诺当前导入目录中存在对应村田候选。没有导入产品目录时，保留原页面的提示，不伪造产品记录。

个人开发版 v2.5 使用项目已有的 `xlsx` 库实现 `.xlsx/.xls` 读取与真正的 `.xlsx` 导出，离线网页将该库一起打包。公司旧 HTML 不一定已包含该库，先检查实际环境。

有工程与现成依赖时复用本地依赖；只有 HTML 时，需要公司允许使用的本地 Excel 解析/生成库并内嵌或打包到最终单文件。不通过 CDN、在线脚本或网络接口临时加载，不关闭浏览器保护，不放宽现有网页网络限制。

如果公司环境确实没有可用的 Excel 库，也无法通过允许的方式获得：先完成 CSV 导入、模板、状态与 CSV 导出，清楚标记 Excel 功能待完成，并说明缺少的本地依赖。不得伪装成完整 v2.5，也不得为了 Excel 支持改写已有翻译引擎。获得依赖后再补齐 Excel 并验收。

## 7. 实施顺序与验收

按以下顺序实施，每阶段做对应检查后继续，不需每个小改动都等待我确认：读取并确认基线 → CSV 读取与选列预览 → 两模式状态与逐行查询 → 结果表与 CSV 导出 → Excel 读取/导出与离线打包 → 回归检查。缺少实际代码、必需依赖或遇到无法解决的错误时，再准确说明阻碍。

以下是必须实际验证的项目。可以在公司本地用单独的合成输入或测试记录验证边界；不要把合成产品混进正式目录，不要为了让测试通过改动公司原始数据。

| 验收项目 | 应有结果 |
| --- | --- |
| 原版与新版启动 | 原版保留；新版正常显示，无新增控制台错误，失败时有提示 |
| 既有单条查询回归 | 相同目录、输入、应用条件下，原版和新版的候选及分类一致 |
| CSV 中文、引号、分隔符 | 正确读出中文与带引号内容，逗号/分号/制表符均能处理 |
| 输入在第 2 列 | 选对列后预览和查询均使用第 2 列，不误用备注 |
| 第 3 行空白 | 有效原行号为 2、4、5，查询和导出不变成 2、3、4 |
| 无标题文件 | 取消标题选项后，第一条输入不被丢弃 |
| Excel 多表与前导零 | 可选工作表；显示格式 `0402` 保留前导零 |
| 所选公式与非法格 | 公式含缓存值仍拒绝；布尔/错误/内部换行说明原行号；原输入不变 |
| 非输入列公式 | 不影响合法输入列的读取 |
| 超限、坏编码、坏引号 | 明确拒绝，无静默截取、无部分替换 |
| 混合有效、失败、无候选输入 | 每条都有结果或原因；导出汇总不遗漏失败项 |
| 切 A/B 与手动清除 | 两模式保留各自内容；只清当前模式；旧异步任务不能恢复内容 |
| 编辑与来源快照 | 新输入解除旧行号关联；此前结果导出仍对应此前查询快照 |
| 普通导出与待核查 | 默认无待核查候选；明确勾选后已选导出正确标记，按查询关联 |
| 多候选和显示更多 | 每候选一行，总数与显示数区分，显示更多后导出同步更新 |
| 真正的 Excel 文件 | 本地生成后重新读取，包含两张正确工作表；文本格无公式 |
| CSV 公式前缀 | 以 `= + - @` 开头的测试文字导出有文本保护，不作为公式运行 |
| 无目录和目录范围 | 不伪造村田候选；样本不宣称全库；现有两个目录文件仍可导入 |
| 离线运行 | 最终 HTML 单文件运行，不新增网络请求；刷新后仍能重新导入并查询 |

至少用模板里的 B 模式两条料号检查现有解析结果：三星样例应为英制 0603、X7R、100nF、±10%、16V；太阳诱电样例应为英制 0201、X5R、4.7uF、±20%、2.5V。如果基线已有规则与此不同，先报告具体差异，不在本次批量改动中悄悄改编码规则。

候选有无取决于公司实际导入目录和应用条件，不能把模板“必须有村田候选”作为验收条件。完整产品目录的统一测试留到后续接入完成；本次只验证当前数据范围与新增文件功能。

## 8. 最终交付与报告格式
