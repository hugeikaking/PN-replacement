村田官方料号查询 · 第三步 v1.0

无需安装软件，不需要 API Key，不用运行 PowerShell 或重扫数据库。

1. 将 Murata-Official-Matcher-v1.html 通过公司允许方式传入电脑并双击打开。
   若传入的是 .html.txt 源码副本，只去掉最后 .txt，保留 .html 扩展名与 UTF-8 编码。
2. 点“选择两个文件”。在第二步成功的 normalize-20261005-143251-410ad0 文件夹里，同时选择：
   normalization-summary.json
   normalized-products.jsonl
   不是原始 Murata_MLCC.json，也不是 audit/review 文件。
3. 显示“已导入2011条规格记录”后输入参数，例如：
   008004 10pF 16V C0G ±2%
   0805 10uF 16V X5R ±10%
   每行一个物料，点“查询官方料号”。
4. 参数缺少容值、电压或尺寸时，显示缺少什么并标为部分匹配。
5. NRND 和其他待核查结果默认折叠，点击展开才显示；缺电压不猜值。
6. 可单个复制，勾选复制多个，或一键复制当前显示的正常生产结果。输出按换行分隔。

只查所导入的样本，没有结果不代表全库没有。参数对应不代表已完成选型、供货或规格书验收。
原翻译网页暂未接入官方查询；先用这个独立入口测试，下一步再统一入口。
所有文件在本地页面内存读取，不上传，不写浏览器持久存储；关闭或刷新后重新选择文件。
本试用版最多128MB/100000条记录，适合现有样本，不要导入368MB原始数据库。

代码、兼容性测试与构建已完成；个人电脑没有公司数据，公司浏览器实际导入和查询尚需验证。
