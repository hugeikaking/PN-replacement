v2.5 → v2.5.1 本地增量升级说明

适用对象
公司电脑上由原来八个 TXT 合并恢复、现在能正常打开的 v2.5 网页。
不需要公司 AI，不需要重新合并那八个文件，不需要安装 Node.js 或 Python。
升级工具仅接受原始 v2.5；如网页经过其他修改或传递时改变了内容，校验不通过会停止。

需要传入公司的两个原始文件
1. Upgrade-PassiveTranslator-v2_5_1.ps1（本地升级工具）
2. Passive-PN-Translator-v2_5-to-v2_5_1.patch.json（功能增量补丁）

通过公司允许的文件传递渠道取得这两个原始文件，保持名称和内容不变。
补丁是普通 JSON 文本，工具本地读取，不联网、不上传数据，也不读取产品目录。
不要复制邮件正文重建文件、手改引号或换行。此前这种传递方式曾造成网页内容损坏。
如果文件传递或脚本执行受公司策略限制，请由 IT 提供批准的渠道或运行方式；本工具不绕过这些限制。

使用步骤
1. 将上述两个文件放在公司当前 v2.5 网页的同一文件夹。
   原网页可能叫 Passive-PN-Translator-v2_5-restored.html，也可以是其他文件名。
2. 在该文件夹打开 Windows PowerShell，运行：

   & ".\Upgrade-PassiveTranslator-v2_5_1.ps1"

   工具会自动寻找该文件夹中与原始 v2.5 完全一致的 HTML。
   如果有多份相同旧网页，或旧网页不在同一文件夹，请明确指定：

   & ".\Upgrade-PassiveTranslator-v2_5_1.ps1" -HtmlPath "D:\个人项目\小项目-料号翻译\2.5\Passive-PN-Translator-v2_5-restored.html"

   上面路径仅为示例，按实际旧网页路径填写。
3. 成功时会显示 Saved: ...\Passive-PN-Translator-v2_5_1.html 和 Upgrade complete。
   新版保存在旧网页旁边；原网页、原八个分片、产品数据都不会被修改。
4. 打开新版 Passive-PN-Translator-v2_5_1.html。
   沿用原来同一批的 normalization-summary.json 和 normalized-products.jsonl，重新在新版网页导入。
   仅为这次描述语法升级，不需要重新下载或转换产品数据库。
   新网页不会自动继承旧网页里的输入、查询结果和已导入数据，需要先自行保留要继续使用的输入。

注意：这两个升级文件不能通过网页的“导入产品目录”按钮导入。
它们先由 PowerShell 读取，生成完整新版网页；网页里导入的仍是原来的两个产品数据文件。

新增行为
- CAP 作为电容标签识别。
- CH0603 / CH0402 / CH0201 按英制封装识别。
- H1.0mm / H0.7mm / H0.39mm 按标称高度识别，严格比较产品的标称厚度。
  不按最大允许高度处理，不自动接受更薄料；不填 H 时不限制高度。
  产品记录缺少标称厚度时，不能靠最大厚度或猜测满足 H 条件。
- +/-20% 继续按 ±20% 处理。
- RO 暂时含义未知，明确标为待确认；按已识别参数提供候选，但只标部分参数匹配。
  不把 RO 自动当成 RoHS，也不宣称已满足 RO 要求。
- 查询诊断包含标称高度；候选导出末尾追加标称高度(mm)、最大高度(mm)。
- 其他无法识别的词仍报错，参数冲突仍报错。
- 保留 v2.5 的应用筛选、标准/特征、两种翻译模式、切换保留、手动清除、批量导入和导出。

这次升级不增加产品目录覆盖范围，也不接入其他产品类别。
候选数量仍取决于实际导入的数据。包含 RO 的以下七行不应标为精确参数匹配。

测试输入（一次粘贴七行）
CAP X6S 22uF +/-20% 10V CH0603 H1.0mm RO
CAP X5R 10uF +/-20% 6.3V CH0402 H0.7mm RO
CAP X6S 4.7uF +/-20% 10V CH0402 H0.7mm RO
CAP X5R 4.7uF +/-20% 6.3V CH0201 H0.39mm RO
CAP X5R 2.2uF +/-20% 6.3V CH0201 RO
CAP X6S 1uF +/-20% 6.3V CH0201 RO
CAP X5R 1uF +/-20% 6.3V CH0201 RO

应检查：
- 不再把 CAP、CHxxxx、上述合法 H 格式当作不认识的字符。
- RO 显示待确认，候选显示部分参数匹配。
- 前四行按各自标称高度限制，后三行不限制高度。
- 没候选时查看诊断，不能仅因官网存在相近产品就取消高度或其他条件。

校验与常见提示
- Patch integrity check failed：
  功能补丁内容与原件不同，请重新通过公司允许渠道取得原文件。没有生成新版。
- selected HTML differs from the original / not the original v2.5：
  选择了其他版本、被修改或损坏的文件。本工具不会尝试猜测修复。
- No original v2.5 HTML：
  旧网页没有放在同一目录，或文件内容不符合原版；先明确指定 -HtmlPath。
- More than one v2.5 HTML：
  找到多份相同旧网页，使用 -HtmlPath 明确选择一份。
- already exists：
  新版文件已经存在，工具不会覆盖；先确认已有文件，必要时自行移到其他位置保存。
- Final HTML integrity check failed：
  停止，未写出 HTML。不要去掉校验继续生成。
