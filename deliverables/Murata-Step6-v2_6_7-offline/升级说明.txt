# v2.6.7：复制报价需要数据

按用户于2026-10-30确认的公司报价规则新增。查询、替代、超高参考和原导出规则保持不变；不向内部系统提交申请，不联网读取模板或上传数据。

## 使用

1. 导入原有同次 `normalization-summary.json` 和 `normalized-products.jsonl`，照常查询并勾选村田料号。
2. 点击结果工具栏的 **复制报价需要数据**。未勾选时按钮不可用。
3. 在弹窗核对料号、规格/替代差异、Y40和用量。每个不同料号一行；同一料号的多条已选查询提示合并显示。分类未知或冲突必须手动选择Y40后才能复制。
4. L生成1～100的随机整数，可手动修改，M即时显示100000×L的数值。同一次查询中关闭弹窗再打开及重复复制不会重新随机；清除或重新查询后重建。随机用量并非客户实际需求，按业务需要核对。
5. 点击 **确认复制报价数据**。在原公司申请表单击 **A5** 或下方一条空白数据行的A单元格，再按Ctrl+V；不要点击A列标题，不要在单元格编辑状态粘贴。每个料号占一行，无标题行。

复制范围为A～AR的44列，空列用定位占位保留；会覆盖目标矩形中原有内容，包括M原公式。前四行不包含在复制内容内，请勿从A1粘贴。若浏览器拒绝复制，展开“手动复制备用”，点击内容框全选后Ctrl+C，保留开头两个空列的定位字符。剪贴板同时提供HTML表格和制表符文本，实际Excel的粘贴设置仍须在公司环境核对。

## 确认的列映射

| 列 | 字段 | 生成内容 |
|---|---|---|
| C | Register/Update Target data | `Y`，按用户确认，不采用截图中的Register/Update示例 |
| G | muRata P/N | 勾选的导入目录料号，不生成或拼接新料号 |
| I | Y40 | 目录Series为GCM：`ADAS-OT`；其他明确AEC-Q200：`IVI-OT`；明确非AEC且属于民用/工业应用：`WLMD5G` |
| J | Application Detail | `IoT module` |
| K | Set Qty | `100000` |
| L | Usage | 1～100随机整数，可修改 |
| M | Demand Qty | K×L的计算数值，不复制或重建复杂公式 |
| O | Unit | `pcs/month` |
| P～T | Description / AEC / Conversion Request | 全部留空，用户确认本次不填写翻译申请内容 |
| 其余列 | 系统及非填写列 | 全部留空 |

I列映射是公司报价路由，不是新增认证或Grade判断。GCM依据目录明确Series字段；AEC依据明确产品特点或合规字段。特点AEC与合规false冲突时不自动分配；未知或不属于工规的记录也不自动当工规。弹窗可按实际用途选择三种Y40代码，不改变原产品数据。

明确勾选的待核查、替代和超高参考允许进入报价清单，但弹窗保留原查询提示和规格差异；不会因此变成精确匹配或选型验收。按本次要求P～T为空，这些提示不写入申请表，操作前在弹窗核对。

## 公司电脑升级

本次以原v2.6.6为基础，无需重新整理产品目录。通过公司批准渠道取得：

- `Upgrade-PassiveTranslator-v2_6_7.ps1`
- `Passive-PN-Translator-v2_6_6-to-v2_6_7.patch.json`

与原v2.6.6 HTML放在同一目录，运行：

```powershell
& ".\Upgrade-PassiveTranslator-v2_6_7.ps1"
```

原件改名时可加 `-HtmlPath ".\当前网页.html"`。升级器严格接受原v2.6.6 SHA256 `376F4DD1CB98B2EDC8D49669B937A0E6F77BFD7F8982E26A1B0DCC8D1F2CD1BC`，另存v2.6.7，不覆盖旧网页；拒绝损坏补丁、输入和已有输出。不读产品数据、不联网。也提供完整v2.6.7 HTML作为备选。

## 验收

先在申请表副本中测试：选择工规、GRT/AEC、GCM各一个，检查I分别为WLMD5G、IVI-OT、ADAS-OT。确认C是Y，J/K/O固定，L是整数，M为K×L，P～T及其他非填写列为空。检查前四行不变、44列未错位、重复复制用量不变；修改L后M同步变化。公司实际模板、保护及系统导入仍由用户本地验收。
