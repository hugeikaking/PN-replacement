# 物料与料号互译 v2.5

打开本目录 `Passive-PN-Translator-v2_5.html`。沿用公司已有的两个规格数据文件，不需要为了批量功能重新整理数据库。

新增：Excel/CSV 批量导入、选工作表与输入列、预览、原表行号、结果 Excel/CSV 导出。两个翻译模式均可用，每次最多100条，文件不超过5MB。CSV 请从 Excel 另存为“CSV UTF-8”；每格一个完整描述或料号。

查询后，普通导出仅包含当前显示的正常生产候选；待核查料号需明确勾选并使用“导出已选料号 Excel”。失败和无匹配的输入仍在查询汇总中，不自动选料。不包含公司产品数据库，也不填写公司报价申请表。

应用、标准、特征保持 v2.4 的原 JSON 字段优先规则。已导入的是样本就只查样本；完整产品目录与公司 API 在后续阶段验证，报价申请 Excel 自动填写最后做。
